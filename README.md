# RAJA ENTERPRISE Stock Management System — V1

Flutter starter app for a premium stock-management dashboard.

## Included
- Dashboard
- Product list and search
- Add Product
- Stock In / Stock Out quick controls
- Low-stock alerts
- Purchase and selling price
- Stock value summary

## Run
1. Create/open a Flutter project.
2. Replace `pubspec.yaml` and `lib/main.dart` with these files.
3. Run:
   flutter pub get
   flutter run

This V1 uses local in-memory data. Firebase, authentication, persistent database, sales, invoices, customers, suppliers and reports can be added in the next phase.
